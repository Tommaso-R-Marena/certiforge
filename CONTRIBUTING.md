# Contributing

Keep claims scoped to actual evidence. Never promote sampled checks, model predictions or game scores to formal proof. Every proposed change requires exact-source validation and independent human review before protected integration.

New human contributions should include a Developer Certificate of Origin 1.1 sign-off only when the contributor can truthfully make that certification: https://developercertificate.org/. This prospective policy does not retrospectively establish rights to existing commits, AI output, institution-owned research, datasets or assets. Record provenance and license obligations; leave unresolved ownership OPEN.

Report security issues through SECURITY.md. Do not include secrets, private user records or uncleared research in issues, patches or logs.
